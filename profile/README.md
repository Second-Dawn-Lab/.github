## What is Second Dawn?

Second Dawn builds **free, open-source desktop apps** that run **fully on your own computer**. No accounts, no subscriptions, no tracking, and your data never leaves your machine. Our apps are named after birds.

## Apps

| App | What it does | Status |
|---|---|---|
| 🦉 **[Owl-L](https://github.com/Second-Dawn-Lab/owll)** | Offline translator: text, documents, Ctrl+C+C popups, screen-area translation, live captions and an optional local AI Quality mode | ✅ [Download](https://github.com/Second-Dawn-Lab/owll/releases/latest) (Windows 10/11) |
| 🪹 **Nest** | One place to install, update and manage all Second Dawn apps | ⏳ Coming later |
| ➕ *More coming* | Got an idea? Open an issue! | — |

## Why Second Dawn?

- **Free forever.** MIT licensed, no paywalls, no "pro" tier.
- **Offline first.** Works without internet once set up.
- **Private by design.** Your text, files and screenshots stay on your device.
- **Lightweight.** Built to run well on everyday laptops, no GPU needed.
- **Shared, not duplicated.** Apps share models and components, so you never download the same thing twice.

## Code signing policy

Free code signing provided by [SignPath.io](https://signpath.io), certificate by [SignPath Foundation](https://signpath.org). Our apps' installers are built from the public source on GitHub Actions, and every signing request is approved manually. Details: the [Owl-L code signing policy](https://github.com/Second-Dawn-Lab/owll/blob/main/docs/CODE_SIGNING_POLICY.md).

**Privacy:** our programs do not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating them. Security reports: see the [security policy](https://github.com/Second-Dawn-Lab/owll/blob/main/SECURITY.md). Conduct: [Code of Conduct](https://github.com/Second-Dawn-Lab/owll/blob/main/CODE_OF_CONDUCT.md).
